# Studex---Webdesign
Webdesign for a University student portal (Login screen, Home page). Pure HTML/CSS.

## Screenshots

**Login**
![Login screen](screenshots/login.png)

**Dashboard**
![Dashboard](screenshots/dashboard.png)

## Features
- Branded login screen with split-panel layout
- Student profile shown as an ID-card style header
- Course dashboard with progress tracking
- Fully responsive, down to mobile

## Built with
- HTML5
- CSS3 (Grid, custom properties, media queries)
- Google Fonts — Space Grotesk, Inter, JetBrains Mono

## Structure
```
├── index.html   → login page
├── home.html    → dashboard
└── styles.css   → shared styles
```

## Run it
Clone the repo and open `index.html` in your browser — no build step required.
